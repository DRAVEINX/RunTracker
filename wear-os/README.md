# Wear OS companion

The first implementation targets Android phones. This directory documents the watch scope and is not yet a buildable Wear OS application.

Planned:
- Start, pause, resume and finish workouts from the watch.
- Show elapsed time, distance and pace on a glanceable screen.
- Evaluate watch-based GPS and Health Services exercise APIs.
- Synchronize session state through the Wear OS Data Layer.
- Test disconnection, reconnection and physical-device behavior.

A separate native Kotlin + Compose for Wear OS module must be built and tested before watch support can be called available.
